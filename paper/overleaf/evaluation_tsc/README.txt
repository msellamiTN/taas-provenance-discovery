Section 8 (Experimental Evaluation) of the PaMCP manuscript, journal version (fits the 6-page budget:
pp. 13-17 in the preview plus references).

Contents
  evaluation_tsc.tex          the section (tables inlined; \label{sec:ev}, sec:ev-rq1 ... sec:ev-threats)
  figures/            6 vector figures used by the section
  evaluation_tsc.bib          the 7 references it cites (merge into your .bib if the keys are not already there)
  ../evaluation_tsc_test.tex   (zip root) compiles the section on its own: an optional check

Use in Overleaf
  1. Upload this folder to the project root, next to paper.tex (keep the folder name "evaluation_tsc").
  2. In the preamble of paper.tex (skip what is already there):
       \usepackage{graphicx}
       \usepackage{booktabs}
       \usepackage{amsmath}
       \usepackage{url}
     The section defines \pamcp only if paper.tex does not (\providecommand).
  3. Replace the old evaluation section with
       \input{evaluation_tsc/evaluation_tsc}
     placed before the Conclusion.
  4. Add the entries of evaluation_tsc.bib to the paper's bibliography file, or list both files:
       \bibliography{paper,evaluation_tsc/evaluation_tsc}
  5. Cross-references to the rest of the paper used in the text: Fig. 1, Fig. 3, Alg. 1, Definition 6,
     Proposition 1, Proposition 3, Property 1, Eq. (5), Eq. (6), Sections 5 and 6 (written as plain numbers;
     adjust if the manuscript's numbering changes).

All numbers come from results/final/*.json and results/revision_2/*.json of the repository; figures are
regenerated by paper/make_eval_r2.py and this folder by paper/package_overleaf.py.
